Interview Explanation

Recommended 60-second answer
“I would implement observability as multiple signals rather than relying on a single monitoring tool. Application and infrastructure logs go to CloudWatch Logs. Application and Kubernetes metrics are collected with Prometheus and stored in Amazon Managed Service for Prometheus. Grafana provides the operational dashboards by combining Prometheus metrics with CloudWatch metrics. For distributed tracing, I would instrument the applications with OpenTelemetry and use AWS X-Ray or the selected tracing backend to follow a request across services. This gives us logs for detailed events, metrics for health and trends, dashboards for operational visibility, and traces for understanding latency and failures across distributed services.”
