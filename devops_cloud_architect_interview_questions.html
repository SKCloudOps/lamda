Kubernetes and EKS

What types of applications have you deployed?

Web applications such as Java Spring Boot and Node.js, microservices, MySQL and MongoDB databases, Kafka, Prometheus, Grafana, Jenkins, and containerized workloads running on Docker and Kubernetes. I describe the deployment, security, observability, scaling, and recovery responsibilities for each platform.

How do you find the pod consuming the most resources?

Use kubectl top pods -A --sort-by=cpu or kubectl top pods -A --sort-by=memory, then inspect the selected pod with kubectl describe pod and compare usage with requests, limits, restarts, and node capacity.

How do you deploy containers on different Kubernetes nodes?

Use replicas with topology spread constraints, pod anti-affinity, node selectors, node affinity, taints, and tolerations. The scheduler then places pods according to resource availability and the declared placement rules.

What are readiness and liveness probes?

Readiness controls whether a pod receives traffic. Liveness detects an unhealthy running container and triggers a restart. A startup probe is useful for slow-starting applications so liveness does not restart them prematurely.

How do you scale five pods to ten?

kubectl scale deployment/<deployment-name> --replicas=10 -n <namespace>
kubectl rollout status deployment/<deployment-name> -n <namespace>

How do you troubleshoot a Kubernetes application?

Start with scope and timing, then inspect pods, events, logs, probes, services, EndpointSlices, Ingress or ALB health, DNS, NetworkPolicy, resource pressure, and dependencies. Correlate metrics, logs, traces, and deployment events before applying the smallest safe remediation.
kubectl get pods -A
kubectl get events -A --sort-by='.lastTimestamp'
kubectl describe pod <pod> -n <namespace>
kubectl logs <pod> -n <namespace> --previous

Monitoring and Observability

How do you configure Prometheus and Grafana?

Deploy Prometheus with Helm or manifests, configure Kubernetes service discovery and scrape targets, deploy Grafana, connect it to Prometheus, import or build Kubernetes dashboards, and define Prometheus or Grafana alert rules with notification routing.

How do you visualize metrics for twenty pods?

Use Prometheus labels such as namespace, workload, pod, container, and node. In Grafana, create variables for namespace and workload, then graph CPU, memory, restart count, request rate, error rate, and latency across all selected pods.

Which observability tools do you use?

PrometheusGrafanaAlertmanagerCloudWatchFluent BitOpenSearchLokiOpenTelemetryJaegerAWS X-RayCloudTrailELK

Use metrics to detect, logs to explain, traces to localize latency, and events to provide deployment or platform context.

How do you investigate a production performance incident?

Define the time window and affected path, compare golden signals with a healthy baseline, identify the first failing trace span, correlate request and trace IDs with logs, inspect Kubernetes and cloud events, validate the suspected dependency, mitigate safely, and continue monitoring after recovery.

Terraform and Infrastructure as Code

What is Terraform taint?

The legacy terraform taint command marked a resource for recreation. In current Terraform, prefer a planned replacement with terraform apply -replace='aws_instance.example' so the replacement is explicit and reviewable.

How do you secure a Terraform state file?

Use a remote backend such as S3 with encryption, versioning, strict IAM, access logging, and state locking. Treat state as sensitive because it can contain resource attributes and secrets. Separate state by environment or ownership boundary and never commit it to source control.
terraform {
  backend "s3" {
    bucket         = "company-terraform-state"
    key            = "platform/prod/terraform.tfstate"
    region         = "us-east-1"
    encrypt        = true
    use_lockfile   = true
  }
}

What happens if fifty of one hundred managed VMs are deleted manually?

Terraform refreshes state during planning, detects the missing resources, and normally proposes recreating them to match configuration. Review the plan first; do not apply blindly, especially when replacement affects dependencies or data.

What is the syntax for for_each?

variable "instances" {
  type = map(object({
    ami           = string
    instance_type = string
  }))
}

resource "aws_instance" "example" {
  for_each      = var.instances
  ami           = each.value.ami
  instance_type = each.value.instance_type
  tags = { Name = each.key }
}

How do you bring unmanaged resources under Terraform?

Write the resource configuration, import the existing resource into the correct address, run terraform plan, and reconcile differences until the plan represents the intended state. Import does not generate a complete configuration automatically.
terraform import aws_vpc.example vpc-1234567890abcdef0
terraform plan

Docker and Containers

What are the advantages and disadvantages of multi-stage Docker builds?

Advantages: smaller runtime images, fewer build tools in production, reduced attack surface, and better separation of build and runtime concerns. Tradeoffs: more Dockerfile complexity, possible cache mistakes, and harder debugging of discarded intermediate stages.

What is the difference between CMD and ENTRYPOINT?

ENTRYPOINT defines the executable, while CMD supplies default arguments or a default command. The exec form is preferred for signal handling.
ENTRYPOINT ["python", "app.py"]
CMD ["--port", "8080"]

What is the difference between bridge and host networking?

Bridge networking gives containers an isolated network namespace and virtual IPs. Host networking shares the host network namespace, which can reduce overhead but weakens isolation and creates port conflicts.

How do you persist data in Docker?

Use named volumes for Docker-managed persistence, bind mounts when a host path is intentionally required, and external managed storage for production databases. Containers should remain replaceable.
docker volume create app-data
docker run -v app-data:/var/lib/app my-image

CI/CD and Jenkins

Describe an end-to-end CI/CD workflow.

A developer commits code, CI checks out the revision, runs unit and integration tests, scans dependencies and images, builds an immutable artifact, publishes it to a registry, deploys through approved environments, and observes health metrics before promotion or rollback.

Write a Jenkins pipeline with approval before production.

pipeline {
  agent any
  stages {
    stage('Checkout') { steps { checkout scm } }
    stage('Build and Test') { steps { sh './mvnw clean verify' } }
    stage('Image') { steps { sh 'docker build -t registry/app:${BUILD_NUMBER} .' } }
    stage('Approval') { steps { input 'Deploy to production?' } }
    stage('Deploy') { steps { sh 'kubectl apply -f deployment.yaml' } }
  }
}

How do you handle a failed Jenkins build?

Review the first meaningful error in console logs, identify whether it is code, dependency, agent, credential, infrastructure, or test related, reproduce it, fix the owning layer, rerun validation, and preserve the failure evidence. Archive JUnit XML and other build artifacts for trend analysis.

What is a Jenkinsfile and where is it stored?

A Jenkinsfile is pipeline-as-code, normally stored in the root of the application repository and reviewed with the same pull request process as application code.

AWS Architecture

Which AWS services do you use in a microservices CI/CD platform?

IAM, VPC, Route 53, ALB or NLB, ECR, EKS, S3, CloudWatch, CloudTrail, KMS, Secrets Manager, CodeBuild or Jenkins, CodePipeline where appropriate, and RDS or DynamoDB for data services.

How do you handle a sudden e-commerce traffic spike?

Use CloudFront caching where suitable, verify ALB and application health, scale pods and nodes, protect databases with connection limits and caching, add read capacity where appropriate, inspect queue depth, and use dashboards and alerts to guide changes.

How do you make a single-instance application highly available?

Deploy multiple instances across Availability Zones in an Auto Scaling Group, place an ALB in front, configure health checks, externalize session state, and use Multi-AZ database capabilities with backups and tested failover.

How do you provide cross-account S3 access?

Create a least-privilege role in the bucket account, add a trust policy for the approved principal from the other account, grant the required S3 permissions, and use STS AssumeRole. Validate both identity policy and bucket policy, plus encryption key policy if KMS is used.

What is the difference between a load balancer and NAT gateway?

A load balancer distributes inbound traffic to healthy targets. A NAT gateway provides outbound internet access for private resources without allowing unsolicited inbound connections. They solve different traffic-direction problems.

Security and Secrets

Should secrets be stored in ConfigMaps?

No. ConfigMaps are for non-sensitive configuration. Use Kubernetes Secrets with encryption at rest and least-privilege RBAC, or integrate AWS Secrets Manager or HashiCorp Vault through an approved external-secrets pattern. Avoid putting credentials in images, Git, logs, or plain environment files.

How do you securely store GitHub or CI credentials?

Use repository, environment, or organization secrets; prefer OIDC federation to short-lived cloud credentials; restrict permissions; mask values in logs; rotate credentials; and audit workflow access.

How do you check code and infrastructure vulnerabilities?

Use SAST and dependency scanning, secret scanning, image scanning, IaC scanning, dynamic testing such as ZAP where appropriate, AWS Inspector, runtime policy controls, patch management, and an exception process with ownership and expiry.

Linux and Git

How do you count the word devops across HTML files?

rg -oi "devops" --glob "*.html" | Measure-Object -Line
# Linux alternative:
grep -oi "devops" -- *.html | wc -l

What does break do in shell scripting?

break exits the nearest loop immediately when a condition has been met, such as finding a matching record or handling a terminal error.

How do you resolve merge conflicts?

git status
# edit conflict markers: <<<<<<<, =======, >>>>>>>
git add <resolved-files>
git commit -m "Resolve merge conflict"
git push

How do you change the latest commit message?

Use git commit --amend -m "New message". If the commit was already shared, coordinate with the team and prefer git push --force-with-lease rather than an unconditional force push.

Scenario and Behavioral Questions

Describe a difficult production incident.

Use a concise Situation, Task, Action, Result structure. Explain how you detected the issue, reduced user impact, communicated status, validated the fix, and prevented recurrence. Include measurable results where possible, without claiming experience you do not have.

How do you approach cost optimization?

Start with usage and ownership data, then right-size compute, use autoscaling, select Spot capacity for interruptible workloads, apply storage lifecycle policies, remove unused resources, optimize data transfer, and track savings without reducing reliability or security.

How do you manage data loss risk for critical applications?

Define RPO and RTO, use synchronous or asynchronous replication as appropriate, automated encrypted backups, point-in-time recovery, cross-region copies where justified, access controls, integrity checks, and regular restore and failover exercises.

What are your daily DevOps responsibilities?

Monitor reliability and security, support deployments, automate infrastructure and delivery, troubleshoot incidents, review changes, improve cost and performance, maintain documentation, and collaborate with development and product teams.
